# ASECNA Air Traffic Intelligence

Système intelligent de prédiction de la congestion du trafic aérien basé sur les données ADS-B et le Machine Learning.

## Objectif

Le projet vise à analyser le trafic aérien et à prédire la congestion à court terme, notamment à un horizon de +2 heures.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Streamlit
- Plotly
- PyDeck
- Git / GitHub

## Fonctionnalités

- Collecte de données ADS-B
- Prétraitement des données
- Feature engineering
- Calcul de l'indice de congestion
- Prédiction de la congestion à +2h
- Visualisation interactive
- Dashboard Streamlit
